Put Lua plugins here, one folder per plugin: lua/plugins/<name>/plugin.lua
The folder name is the plugin's name: lower-case letters, digits and _ only.

A plugin runs when its name is in rp_lua_plugins (galaxyrp_server.cfg), or after
/scripts enable <name> until the server restarts. lua/examples has three to start from,
and lua/lua_api.md explains how to write one.
