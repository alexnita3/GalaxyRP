GalaxyRP Accounts Database

This folder's accounts.db file is the SQLite database GalaxyRP uses for player accounts and characters. To browse or edit it outside the game, use the Open SQLite Viewer

This is a free, third-party, browser-based tool (by Juraj Novák) that runs entirely client-side — the database file is read locally in your browser and is never uploaded anywhere.

To use it:

  1. Click the button above to open the viewer in a new tab.
  2. Click the drop zone (or drag and drop) and browse to accounts.db in this same database folder.
  3. Browse tables, or run SQL queries against the loaded database.

Source: github.com/inloop/sqlite-viewer
